说到做到的个人助理

每句「我去做」都记进账本；做完附上能核对的出处；你真的收到了，才算兑现。

▶ 60 秒看它怎么面对逾期 打开只读演示

演示数据由脚本生成，走的是真实账本代码，页面不调用任何模型。

账本回放

选一件事，按时间回放它走过的七站：判断、登记承诺、开工、模型、工具、交付、兑现。逾期、做不到、改约都如实显示。

交付附原文，逐字核对

关键结论要附资料原文；验收时核对它确实出自这次读过的那一版，核对不过就不交付。回复层不能口头许诺，要做就真的接下来。

记忆星系

五类记忆画成五团星：确认过的是亮星，待确认的是虚线，被取代的旧记忆是残骸并指向新记忆。推断出的记忆要你确认才生效。

演示里的四件事

  • 整理周会纪要：先拦下一句口头许诺，再真的接下，读资料、交付、按出处兑现。
  • 三点前要报价对比表：中途出错卡住，如实告知；过了三点，账本只提醒一次逾期。
  • 每天七点打电话叫醒：做不到就直说，承诺记为「做不到」，不挂着装没事。
  • 四点前写通知，用户改到五点：旧承诺被替换，新承诺按时兑现。

怎么做的

  1. 回复层判断
  2. 登记承诺
  3. 开工
  4. 模型请求
  5. 工具调用
  6. 交付
  7. 兑现
  • Python asyncio 服务 + SQLite 账本：每一步都是账本里的一行，回放只读这些行。
  • 执行循环复用 Pi Agent（pi-agent-core 1.5.0），经 Node 24 子进程桥接；工具和权限留在 Python 一侧。
  • 模型用 DeepSeek flash 官方 API，搜索与读网页用 DeepSeek Search/Fetch。
  • 前端零依赖：回放的像素画和星系都是 Canvas 代码绘制，不含外部素材。
