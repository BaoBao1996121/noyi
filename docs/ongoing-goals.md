# 用持续目标照看一件事

在会话左侧打开“持续目标”，创建长期职责并选择负责人。目标属于当前私聊或群聊；私聊资料不会因助理加入群聊而自动共享。

添加检查计划时，写清每次应交付的成果，列出要读取的 UTF-8 文件完整路径或无需登录的文本网址。文件每份最多 128 KB，支持 `.txt`、Markdown、JSON 等文本，不自动读取目录、PDF、Office、登录页或网页脚本。

可以选择资料变化检查、固定间隔、当地日期时间。默认使用 `Asia/Shanghai`。注册成功后页面显示下一次检查和来源健康。资料没有变化时不调用模型；“立即检查”是明确要求，即使未变化也会按模板处理一次。暂停目标会一起暂停它的未完成工作；恢复保留预算和问题。

同一计划已有工作尚未解决时，后续资料变化合并为最近一次等待处理。若上次任务失败、需要回答或已暂停，请从“查看工作”进入处理；不要通过新建同样的计划绕过它。修改计划会建立新版本并暂停旧版本未完成的工作；旧记录保留。

模型调用和工具额度是整个持续目标的累计上限，包含根任务与 Worker。增加额度不会清零用量。单次任务还有自己的预算；如果单次工作已用完，先处理该任务的额度，再恢复目标。

“自动接手规则”管理新的隐式工作，和检查计划分开。目前通过“添加一条线索”录入文字，没有自动接入外部 CI 或聊天账号。可选：

- **关闭**：不从新线索产生工作。
- **仅观察**：记录哪些线索会被接手，便于验证规则，不调用模型。
- **自动接手**：匹配关键词且未过期、未超过次数和冷却限制时，创建有明确模板与预算的任务。

切换模式只影响之后的新工作；已接下的工作继续按原授权执行。要停已有工作，请暂停任务或目标。旧的观察判断不会因为打开自动接手而回头自动执行。

助理可以提出有证据的计划时间调整。默认由你确认；创建目标时可明确授权负责人在有限范围内审核调整频率。建议本身不代表已经生效；界面的新版本注册记录才是执行依据。模型不能借此增加来源或预算。

服务运行在这台电脑上。关闭浏览器仍继续运行，关闭服务或关机就暂停执行；再次启动时按照合并、跳过或补一次的设置处理漏检。不要把 localhost 界面直接公开到互联网。本版没有远端调度器或真实外部消息连接，后台稳定性仍需后续持续自用观察。
