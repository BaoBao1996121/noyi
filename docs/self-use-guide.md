# Personal Agent 0.6.0 自用指南

直接把需求告诉助理，它负责理解、执行和跟进。目标、任务、检查计划和执行额度由系统内部管理；日常使用一个对话输入框即可。执行循环使用 Pi Agent Core，默认模型为 Qwen 官网 `qwen3.7-plus`。

正式版本统一在仓库 `main` 分支。版本状态及验证进度见 [STATUS](../STATUS.md)，[M5 报告](validation/M5_REPORT.md)保留的是 0.5.0 历史验收，不能代替新版自然语言流程的验证。

## 启动与停止

首次安装：准备 Python 3.11+、Node.js 22.19+，双击仓库根目录的 `Install.cmd`。依赖版本保存在 `requirements-lock.txt` 和 Pi 的 `package-lock.json`。

日常使用桌面快捷方式「启动 Noyi」「停止 Noyi」即可；也可以在仓库根目录执行 `noyi start`、`noyi stop`、`noyi restart`，或双击 `Start Personal Agent.cmd` / `Stop Personal Agent.cmd`（两者等价）。启动会在后台开启服务并打开 <http://127.0.0.1:8765>，重复启动会打开同一份服务。关闭浏览器后仍会继续工作，需要显式停止才会结束。停止会保存执行状态，下次启动继续处理已接收的工作；想让某件事不再继续，可以先在对话中明确说“暂停这件事”或“取消这件事”。没有注册开机自启，也没有开放公网访问。

执行 `noyi status` 可随时查看服务是否在运行、访问地址与进程号；`noyi restart` 等同于先停止再启动。

模型凭据在左下角设置中保存，或沿用本机 `DASHSCOPE_API_KEY` 环境变量。设置页不会回显密钥。配置与选型说明见 [模型配置](model-configuration.md)。真实调用会使用你的账号额度。

## 第一次交代事情

进入“个人助理”，在输入框直接说：

> 对照这两份资料，整理现行负责人、截止日期、变更和待确认事项，不补造缺失信息。

需要资料时可以附上 UTF-8 文本、Markdown、JSON、CSV 等文件，每份最多 128 KB，或添加明确的 HTTP/HTTPS 文本网址。PDF、图片、Office 文档和语音需先转换，本版没有识别这些格式的入口。

发送后可以切换会话；进展、问题和成果会保留。如果缺少必要信息，助理会直接问你。你可以在同一个输入框回答、补充要求，或者交代另一件事。选中左侧某件事便于查看上下文；“回复”按钮可以明确指向某条消息。

例如：

- “清单里的截止日期改到周五。”
- “这件事现在进展怎样？”
- “先暂停整理活动资料。”
- “继续处理活动资料，保留已经完成的部分。”
- “另外，帮我整理明天的出行清单。”

当多件事都可能是你说的“那个”时，助理应问一句具体指哪件。你也可以在消息中直接写事项名称。内部执行有用量边界；明确说继续后会在受限范围内续接，历史进度、失败和消耗仍保留。

成果完成后可以查看或下载，再直接告诉助理需要怎样修改。“这份成果怎么样”是可选的反馈入口，耗时等使用记录也可以不填。短而连贯的工作优先直接处理，确有分工价值时再使用后台协作者。

## 让一件事持续有人管

仍然在对话里说，例如：

> 以后帮我留意 `C:\Documents\项目进展.md`。有变化时更新行动清单，列出新增事项、改动的负责人和日期。

助理会在已有信息和授权范围内安排持续跟进，并在真实登记后说明正在如何处理、下一次何时查看。资料范围不清楚时，会问你要跟进哪份资料。详细说明见 [持续跟进](ongoing-goals.md)。

“正在跟进”是可选的进展查看页，可以看到已交代的事情、最新情况、下一步安排和已有成果。调整安排也直接说：

- “项目资料改为每周五上午九点检查。”
- “项目资料先暂停。”
- “继续跟进项目资料。”
- “这个项目结束了，以后不用再跟进。”

页面同时保留暂停、继续、结束的便捷按钮。

**上传的文件是副本。** 上传后，你电脑上的原文件即使改动，副本也不会自动更新。要跟进实时变化，需要明确提供原文件的完整本地路径或无需登录的文本网址；否则请在对话中发送新版本。助理不会由一个文件路径自动取得整个目录、邮箱或其他账号的访问权限。

本机服务运行时才能检查。资料没有变化时，变化检查不调用模型、不反复通知；读取失败会保留异常，不能当成“没有变化”。关机或停止服务期间不会执行，重新启动后按已登记的漏检处理方式继续，不假装一直在线。

当前支持资料变化和周期跟进。单次定时提醒、外部邮箱/日历账号连接、通用电脑操作尚未接入。

## 看成果和已有回顾

需要回顾时也直接说，例如：“帮我回顾一下项目资料的跟进情况，按实际执行记录说话，没有测量的业务效果保持未知。”助理会建立真正的复盘工作，完成后把报告留在对话里；接下请求不代表报告已经完成。

成果保留来源引用和执行记录。已有回顾报告可从“正在跟进”中查看；报告中的账本事实由程序直接生成，模型建议单独列出，原始文本和证据仍可追溯。

完成一项工作不等于现实目标已经实现。没有采纳率、满意度、长期质量或完整人工耗时的数据，就保持未知。模型解释和重要的责任分配、日期仍需对照来源；你可以直接指出错误，让助理修正这份成果。

## 备份与换电脑

在“设置 → 下载备份包”保存 ZIP。包含数据库、成果、已缓存来源、上传资料、观察快照、记忆和跟进记录。**不包含模型密钥，也不包含数据目录外的原始文件**。备份包含私人资料，应按私人文件保存。本版单次备份上限 512 MB、20000 个文件。

换电脑时使用 `main` 分支的版本安装。恢复只写入不存在的新目录，不覆盖现有资料。在仓库目录运行：

```powershell
& .\.venv\Scripts\python.exe -m personal_agent restore 'D:\Backups\personal-agent.zip' --destination '.pa\restored'
& .\.venv\Scripts\python.exe .\scripts\desktop.py start --data .pa\restored
```

先停止原服务再使用同一端口。恢复后重新配置 Qwen Key，确认外部来源路径；未完成工作和持续跟进保持暂停，旧聊天请求与待投递消息不自动重发。管理目录内的资料路径会迁移，目录外的原文件须自行迁移，并向助理提供新位置。恢复库使用独立的浏览器草稿空间。

命令行备份需先停服务：

```powershell
& .\.venv\Scripts\python.exe -m personal_agent --data .pa\personal backup --output 'D:\Backups\personal-agent.zip'
```

## 遇到问题

- 页面断开：重新启动，草稿和已接收的工作仍保留。服务日志在数据目录 `logs/server.log`。
- 同时有多件事：在对话中写出事项名称，或使用“回复”指向具体消息。
- 工作停住：直接问“这件事停在哪里了”。查看原因和已有成果后，可以补充缺失资料、明确继续或结束。
- 来源或模型配置失效：提供正确来源或更新模型配置，然后明确让助理继续。
- 端口被另一份服务占用：用那份服务对应的停止入口关闭；高级用法可通过 `scripts/desktop.py start --port 8766 --data .pa/another` 选择其他端口和资料库。

现阶段适合单人本机文本资料整理、待办跟进和证据回顾。没有远程唤醒、常驻云服务、外部消息投递或 DSH/Pi 原样插件安装器。实现替换接口见 [模块接口](module-interfaces.md)，Pi 接入见 [核心说明](pi-kernel.md)。多日真实使用稳定性和长期效果需要持续积累自用反馈。
