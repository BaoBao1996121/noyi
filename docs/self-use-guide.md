# Personal Agent 0.5.0 自用指南

这是 M1–M5 完整实现后的本地自用版。执行循环使用 Pi Agent Core，默认使用 Qwen 官网 `qwen3.7-plus`。持续目标需要这台电脑和本地服务保持运行。

## 启动与停止

首次安装：准备 Python 3.11+、Node.js 22.19+，双击仓库根目录的 `Install.cmd`。本轮实际验证环境为 Windows、Python 3.13、Node 24.14.1，依赖版本保存在 `requirements-lock.txt` 和 Pi 的 `package-lock.json`。

日常双击 `Start Personal Agent.cmd`，会在后台启动服务并打开 <http://127.0.0.1:8765>。重复启动会打开同一份服务。关闭浏览器后仍会继续工作；双击 `Stop Personal Agent.cmd` 才会停止服务。停止会保存执行状态，下次启动继续处理已接收的工作；想让某件事不再继续，应先在界面暂停或取消它。没有注册开机自启，也没有开放公网访问。

模型凭据在左下角设置中保存，或沿用本机 `DASHSCOPE_API_KEY` 环境变量。设置页不会回显密钥。程序只向配置的 Qwen 官方地址发送模型请求，模型选择依据见 [模型配置](model-configuration.md)。

## 第一次交办

1. 进入“个人助理”，或创建自己的资料管家、复核助理。
2. 添加 UTF-8 文本、Markdown、JSON、CSV 等文本资料，每份最多 128 KB；也可提供明确的 HTTP/HTTPS 资料网址。PDF、图片、语音需先转换，本版没有识别这些格式的入口。
3. 选择“交办任务”，例如：**对照这两份资料，整理现行负责人、截止日期、变更和待确认事项，不补造缺失信息。**
4. 提交后可以切换会话；任务、问题和成果会保留。选中任务后可补充要求、回答问题、暂停、取消或查看成果。
5. 查看成果后点“这份成果怎么样”，记录是否有用、遗漏或事实错误；催办、补充、纠错、接管和耗时可一起记录。未填耗时表示未知。

短而连贯的任务默认优先直接完成。确需分工时明确要求委派，例如让两位 Worker 分别核对当前版本和历史变化，再由负责人整合。协作共享同一总预算；不是每位 Worker 各获一份无限额度。

## 让事情持续有人管

打开“持续目标”，填写想长期维护的事情，再添加真实检查计划。

- **资料变化检查**：定期读取明确授权的来源；没有变化不调用模型，不重复提醒。读取失败会显示健康异常，不能当成无变化。
- **周期检查**：按间隔或指定时区的日期时间执行。计划登记成功才生效；让模型写一份“每周计划”不会自动注册。
- **自动接手规则**：先用“仅观察”查看匹配，再按需要打开“自动接手”；限定关键词、来源、有效期、次数和冷却。本版线索来自本地手动入口，尚未连接邮箱、日历或企业消息。

关闭自动接手只影响新线索；已接手的工作仍属于目标。暂停目标会停止其检查与在途工作，恢复后按当前有效计划继续。目标累计预算与单项任务预算分别限制用量，增加预算不会抹去已有消耗。

## 用证据复盘

在目标中点“复盘已有记录”，会冻结本次观察范围，读取账本、成果和反馈，再保存观察、假设、未知、建议及下一次检验条件。有成果时必须读到完整内容并引用；以前的模型复盘不会被当成新的工作成果反复引用。

“查看复盘报告”和下载文件中的账本事实由程序直接生成，包括观察范围、任务/成果数量、用量、失败和反馈覆盖。模型建议另列，原始生成文本在“模型复盘草稿”中留存；模型把次数或状态解释错时，不会改写已确认的账本事实。

“观察计划”记录要验证的假设、原方案、变化、指标、观察窗口和判定条件。保存它不会自动修改检查策略；到约定时间只产生本地提醒，不自动额外调用模型。复盘提出的新时间需要点击采用才登记；停止观察后不再提醒。

完成任务不代表现实目标已经实现。没有采纳率、满意度、长期质量或真实人工耗时的数据，复盘应保留未知。模型解释仍需核对，重要的责任分配、日期和结论需要对照来源；本轮真实对照仍发现过责任范围推断偏强的措辞。

## 备份与换电脑

在“设置 → 下载备份包”保存 ZIP。包含数据库、任务成果、已缓存来源、上传资料、观察快照、记忆、计划与复盘。**不包含模型密钥，也不包含数据目录外的原始文件**。备份本身包含私人资料，应按私人文件保存。本版单次备份上限 512 MB、20000 个文件。

恢复只写入不存在的新目录，不覆盖现有资料。在仓库目录运行：

```powershell
& .\.venv\Scripts\python.exe -m personal_agent restore 'D:\Backups\personal-agent.zip' --destination '.pa\restored'
& .\.venv\Scripts\python.exe .\scripts\desktop.py start --data .pa\restored
```

先停止原服务再使用同一端口。恢复后重新配置 Qwen Key，检查外部来源路径；未完成任务、目标保持暂停，自动接手关闭，旧聊天请求与待投递消息不自动重发。管理目录内的资料路径会迁移；外部文件和远程账号需要自己重新连接。恢复库使用独立的浏览器草稿空间。

命令行备份需先停服务：

```powershell
& .\.venv\Scripts\python.exe -m personal_agent --data .pa\personal backup --output 'D:\Backups\personal-agent.zip'
```

## 遇到问题

- 页面断开：重新启动，草稿和任务仍保留。服务日志在数据目录 `logs/server.log`。
- 端口被另一份服务占用：用那份服务的停止入口关闭，或使用 `scripts/desktop.py start --port 8766 --data .pa/another`；程序不会强行结束别的软件。
- 预算暂停：检查成果和失败原因后再决定是否增加。持续目标可能还需要增加其累计额度。
- 连续没有新进展：检查来源与要求，再明确继续；历史失败和累计消耗不会清零。
- 来源或模型配置失效：修正配置后明确恢复任务，避免无意义重试。

现阶段适合单人本机资料整理、待办跟进和证据复盘。没有远程唤醒、常驻云服务、外部消息投递、通用电脑控制或 DSH/Pi 原样插件安装器；本轮已提供可验证的实现替换接口，详见 [模块接口](module-interfaces.md)。多日真实使用稳定性和长期效果将随自用继续评估。
