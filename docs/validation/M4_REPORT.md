# M4：持续目标、真实触发与新工作准入

验收日期：2026-11-05（北京时间）。M4 已通过本阶段验收；M5 的证据复盘、对照实验、安装与基本自用调优仍需继续完成。

## 实现与边界

- Goal 持久保存职责、负责人、当前判断、差距、未知、下一步、等待原因、证据与累计预算。一次任务成功不结束目标；暂停、达成、结束均阻止新业务动作。恢复保留原有预算、问题和已观察但尚未处理的变化。
- RoutinePolicy 由本地用户实际注册，保存本地调度器回执、时区、下一次触发、版本与授权记录。支持固定间隔、按星期/当地时间、明确文件或 HTTP 文本的变化检查。写一份计划或模型作出承诺均不会创建调度。
- 时间以 UTC occurrence 身份去重；当地日历使用 IANA 时区。错过的周期可合并、跳过或补一次，不集中重放全部工作。夏令时缺失时刻跳过、重复时刻只运行第一次；Windows 通过 tzdata 提供时区数据，语义依据 [Python zoneinfo](https://docs.python.org/3/library/zoneinfo.html) 与 [datetime](https://docs.python.org/3/library/datetime.html)。
- 检查游标与 observing 记录一起提交；重启继续同一条未完成观察。资料先保存不可变快照与哈希，业务任务只读取该次快照，后续文件变化不能偷换已触发的资料。快照完整性失败时停止，不降级为成功读取。
- 来源健康与内容变化分开记录。必需来源读取失败不会算成无变化，重复失败不重复通知；成功恢复可见。watch 无变化只更新健康计数，不创建任务、不调用模型、不反复提醒。
- 同一计划的旧任务若仍等待、失败或被用户暂停，最新变化会合并等待；不会用不断新建任务绕开问题与预算。用户更新计划后旧回调不能执行新版本；原未完成工作保留为暂停记录。
- 新隐式工作用独立 AdmissionPolicy。首版使用明确关键词、来源/线程、到期、冷却、次数及任务/目标预算；支持 off / observe / auto。只改变之后的新工作准入，不取消已经接下的任务或明确注册的 routine。暂停任务或目标才能停止已接工作。晚到的未决判断必须重新检查规则、目标、受众版本与已有补充责任。
- 模型只能提交带证据、理由和预期成本的现有计划时间调整建议。Worker 无激活权限；用户可以批准，或在明确授权后由当前 Goal 负责人审核，在根任务验收后注册新版本。不能新增来源、扩大预算或任意创建新职责。
- `ObservationSource` 是实际注入的观察接口；替代读取器在故障/晚到测试中使用。适配器是可信安装代码，权限和任务创建仍由账本控制。调度和观察与模型执行分开运行，慢 HTTP 来源不占用用户控制循环。
- WebUI 可创建目标、添加/修改/暂停计划、立即检查、增加累计预算、查看来源与触发记录、审批建议、切换准入模式和录入线索。所有管理提交都有持久 nonce，浏览器丢响应后的重试不重复注册或追加额度。

当前调度器运行在本机服务内；关机、退出服务时不会执行，恢复时按漏触发策略处理。事件入口是本地手动输入或可信安装适配器调用，未连接真实 CI、邮件或聊天服务。没有远端调度器，因此 T32 的远端清理回读部分不适用。

## 真实 Qwen 与墙钟验收

完整原始记录：[live-evidence.json](m4/live-evidence.json)，汇总：[summary.json](m4/summary.json)。采用官网 `qwen3.7-plus`，实际 Pi 执行，没有脚本模型冒充真实调用。

1. 首次读取负责人小林、截止 11 月 8 日的资料，保存进展与引用产物。
2. 三次真实间隔的无变化检查，模型调用保持 4 次。
3. 文件改为小周、11 月 10 日、周五检查，生成新成果；既有来源快照保留。
4. 实际移去来源文件，再恢复原字节：明确记录不可读取、恢复且无变化，没有额外模型任务。
5. 暂停目标后再改文件，新增任务 0；明确恢复后读取小周、11 月 12 日的最新版本。
6. 注册后 60 秒到期的固定间隔计划真实运行。首次观察比到期晚约 5.8 秒，测试脚本当时在完成前一任务；未伪造时钟或把虚拟时间当墙钟验收。
7. 独立普通任务撰写每周三复盘草案，明确说明没有真正启用，不新增周期策略。
8. 重新打开数据库并恢复执行，调用数 **18 → 18**；测试目标在证据收集后暂停。

共 **5 项任务成功，18 次模型调用，124,880 输入 / 3,083 输出 tokens，失败工具操作 0**。四份资料成果与三个实际来源版本比对，负责人、截止、自查/审批边界均一致。模型调用用量全部计入；没有账单金额，不推算人民币费用。

机械验收不代表一般语义正确性。保留两个用词调优点：一份成果把“未知事项”写成“无”，更严谨的说法是“这份资料未列出”；计划说明引用了内部英文状态，M5 将改为自然中文。没有宣称多日运行稳定性或普遍效果提升。

## 浏览器验收

实际创建“河畔清单持续跟进”、授权本地文本、5 秒变化检查、真实产物、暂停、重启服务、恢复。恢复前后累计调用仍为 5。随后实际操作仅观察、自动接手、关闭：

- observe：匹配线索记录“符合规则，尚未自动接手”，无模型调用。
- auto：新线索只创建一项任务，交付“接收时间仍未得到回复，保留待确认状态”的记录。
- off：下一条匹配线索记录未接手，调用不增加。测试完成后目标暂停、规则关闭。

浏览器这组 **2 项任务成功，7 次模型调用，48,608 输入 / 1,208 输出 tokens**。第一项进展记录曾引用无效证据，服务拒绝，模型下一轮改用实际观察回执；该失败及额外调用保留。重启后首次操作的旧页面凭证得到一次 HTTP 403，页面更新凭证并以同 nonce 成功重试，没有重复目标或注册。
