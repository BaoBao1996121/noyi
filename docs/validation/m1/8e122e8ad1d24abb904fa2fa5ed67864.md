# Policy发布流程关键步骤和要求

根据项目资料维护规范（版本2026-11-04，生效2026-11-05）[policy]，发布流程的关键步骤和要求如下：

## 适用范围
适用于所有正式发布资料[policy]。

## 发布前必要步骤
1. **作者自查**：发布前必须由作者进行自我检查[policy]。
2. **独立复核**：需要一名独立复核人进行确认[policy]。

## 必须保存的内容
发布时需保存以下三项内容[policy]：
- 资料版本
- 证据引用
- 行动清单

## 持续管理要求
- **定期复查**：每周三复查未完成的行动项[policy]。

## 禁止事项
- 未经确认的草稿不得标记为正式发布[policy]。

## 总结
发布流程的核心是确保质量控制的两个环节（自查+复核），完整记录（版本、证据、行动清单），以及持续的跟踪管理（周三复查）。只有经过完整确认流程的资料才能被标记为正式发布。
