# 资料维护执行清单（生效日期：2026-11-05）

## 适用范围
适用于所有正式发布资料[policy]。内部临时笔记可先分享但须标明"草稿"，不得冒充正式资料[exception]。

## 例外
仅以下情况允许例外处理：内部临时笔记可以先分享，但必须明确标明为"草稿"状态[exception]。

以下情况**无任何例外**：
- 正式对外发布必须进行复核，不存在免复核例外[exception]
- 紧急修订须由指定复核人当日确认[exception]
- 必须记录变更原因并保留旧版本，不得覆盖历史版本[exception]

## 行动清单
1. **发布前自查**：作者完成自我检查[policy]
2. **独立复核**：邀请一名独立复核人确认[policy]
3. **保存三项内容**：资料版本、证据引用、行动清单[policy]
4. **标记规范**：未经确认的草稿不得标记为正式发布[policy]
5. **定期复查**：每周三复查未完成的行动项[policy]
6. **紧急修订**：由指定复核人当日完成确认，记录变更原因与旧版本[exception]

本清单依据《项目资料维护规范》[policy]与《资料维护例外说明》[exception]整理，两文件均为版本2026-11-04，生效日期2026-11-05。
