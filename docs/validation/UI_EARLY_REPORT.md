# 提前版 WebUI 验收

2026-11-04。位置在 M1 与 M2 之间，属于中间里程碑，不是 M1–M5 的最终交付。

实现三栏会话/聊天/详情与资料库，任务提交、UTF-8 资料上传、精确网址授权、补充、停止/取消、持久问题回答、成果预览/下载、Qwen 官网配置、草稿保存和断线恢复。页面复用同一个真实任务账本与后台服务；没有演示数据冒充执行结果。默认只监听 `127.0.0.1`。

运行：`python -m personal_agent --data .pa/personal web`，打开 `http://127.0.0.1:8765`。未配置凭据时先显示设置入口；保存配置不会被称为连通测试通过。默认模型和官方接口仍见 [模型说明](../model-configuration.md)。关闭服务进程会停止执行，关闭浏览器不停止服务。

## 证据

`tests/test_webui.py` 六项通过：真实 HTTP 上传/提交/同 nonce 去重，来源路径隐藏，跨站/伪造 Host/缺失令牌拒绝，产物哈希校验与越界资料拒绝，后台问题等待和回答继续，密钥不回显及非官方地址拒绝，二进制/超大输入拒绝。

Playwright CLI 实际浏览器检查：中文草稿刷新后保留；上传 policy.txt、填写真实任务、双击发送后仅一个任务；Qwen 完成资料读取与成果交付并在页面预览。第二项任务使用 Qwen 提出“学习/工作”问题，等待期间未自动填写；点击“工作”，刷新后答案按钮失效，模型生成模板。两项真实任务均通过验收，见 [请求与产物证据](ui-early/evidence.json)。中文输入法组合事件的 Enter 没有触发提交；这是浏览器事件检查，不声称已覆盖所有真实输入法软件。

断开浏览器网络后显示断线状态，中文草稿保留；恢复网络后自动刷新已完成任务。人工查看 [桌面截图](ui-early/ui-early-desktop.png) 和 [390px 手机宽度成果预览](ui-early/ui-early-mobile.png)，未见溢出或被遮住的主要操作。离线测试时的网络错误为预期；联网时刷新后控制台无应用错误。首次空 favicon 请求的 404 已用自有图标修正。

## 尚待后续

目前只有默认长期 Bot；多 Bot、群聊、记忆和周期计划按 M3/M4 加入，完整 UI 在 M5 验收。这里只开放文本资料（每份不超过128KB）；不伪造 PDF/OCR、远程电脑、语音或外部渠道能力。模型上下文开销、更多浏览器/输入法和多日稳定性仍需后续验证。当前没有公网访问、移动端配对或系统级自启动。
